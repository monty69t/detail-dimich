# Detail Dimich — лендинг детейлинг-студии

Адаптивный сайт студии химчистки салонов автомобилей в Екатеринбурге.

## Просмотр
Откройте `index.html` в браузере. Внешние зависимости не нужны.

## Файлы
- `index.html` — содержание сайта и отзывы, перенесённые из материалов заказчика.
- `styles.css` — оформление и адаптивная версия.
- `script.js` — мобильное меню и анимации появления.
- изображения `.jpg` — фотографии, скопированные из проекта-референса.
